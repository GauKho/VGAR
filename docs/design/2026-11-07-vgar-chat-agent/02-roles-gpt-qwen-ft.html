Chia vai giữa GPT và Qwen fine-tune

Bên trái là ý bạn vừa nêu, bên phải là cách tôi đề xuất. Màu: GPT, Qwen-FT, host (code tất định), MCP server.

B. Qwen-FT viết hướng dẫn → GPT điều phối
người dùng: "lỗi giảm giá ở đâu? hãy sửa" │ ▼ [Qwen-FT] viết prompt hướng dẫn: "hãy gọi find_task_anchors, rồi get_related_context, rồi sửa is_eligible…" │ model yếu hướng dẫn model mạnh ▼ [GPT] đọc hướng dẫn, gọi tool │ ▼ [MCP] graph / repository / repair │ ▼ [GPT] hoặc [Qwen-FT] sinh diff? ← chưa rõ │ ▼ [host + engine M2] verify → PASS/FAIL Cần fine-tune lại cho vai "viết hướng dẫn": không có dữ liệu gán nhãn, không có cách chấm tự động.
A. GPT điều phối → Qwen-FT sinh diff (đề xuất)
người dùng: "lỗi giảm giá ở đâu? hãy sửa" │ ▼ [GPT] lập kế hoạch, chọn tool, đọc kết quả │ ▼ [MCP] find_task_anchors → get_related_context │ → read_file → analyze_patch_impact ▼ [GPT] gọi tool generate_patch (không tham số) │ ▼ [host] dựng prompt V11 từ template + context │ (tất định, có hash, như thí nghiệm) ▼ [Qwen-FT] sinh diff V11 ← việc đã fine-tune │ GPT không thấy, không sửa diff ▼ [host + engine M2] apply → test → verify │ ▼ [GPT] giải thích evidence cho người dùng Qwen-FT đo được riêng: format V11, tỉ lệ áp được, F1 file/hàm, so bản gốc trên cùng prompt.
