## Contract và handoff cho M2/M3

### API nội bộ M1

```python
TaskAnchorFinder(document).find_task_anchors(issue_text, failing_tests)
TaskOverlayBuilder(document).build(task_id, issue_text, failing_tests)
GraphContextRetriever(
    document, repository_root,
    count_tokens=counter, counter_label=counter.counter_label,
).get_related_context(anchor_ids, budget_tokens, issue_text=issue_text, overlay=overlay)
```

M2/M3 đọc ContextPayload từ `vgar.contracts.context`; import cũ qua
`vgar.graph.context` vẫn trả cùng class ở bản dev. Fields gồm graph_version,
anchor_ids, items, total_token_count, token_budget, truncated; mỗi item có
node_id/path/symbol/range/snippet/relevance/graph rationale/confidence/token_count.
Không thêm public schema_version. graph_version chỉ định danh snapshot;
overlay_id và retrieval diagnostics hiện là sidecar nội bộ M1.

Budget **8000** đã được duyệt cho snippet text. Instructions, issue text,
metadata/separators, chat template/special tokens và response reserve do prompt
layer M3 phân bổ; total_token_count không đại diện tổng prompt. Runtime M3 chưa
được đồng bộ pinned model revision trong phần công việc M1 này.

Tokenizer: `Qwen/Qwen3-4B-Instruct-2507`, revision
`cdbee75f17c01a7cc42f958dc650907174af0554`; tokenizers runtime **0.22.1**.
[Tokenizer manifest](../artifacts/m1/tokenizer-acceptance/tokenizer_manifest.json)
ghi SHA256/source URLs và đường dẫn tương đối tới bốn assets. Assets nằm ở
`artifacts/m1/tokenizers/Qwen3-4B-Instruct-2507/<revision>/`, được Git-ignore;
máy nhận bàn giao cần provision riêng theo manifest.

## Môi trường và cách kiểm tra lại

Môi trường checkpoint đã dùng Windows CPython 3.12.14, tree-sitter 0.25.2,
tree-sitter-python 0.25.0, Jedi 0.20.0, Pydantic 2.13.5 và tokenizers 0.22.1;
các dependency MCP cần cho contract/query tests phải có trong môi trường nhận.

**Kiểm tra tại thời điểm viết handoff:** đường dẫn Python cũ
`D:/KLTN/M1/.venv-win/Scripts/python.exe` và thư mục runtime cũ
`D:/KLTN/M1/tokenizer-runtime` hiện không tồn tại. Cần chuẩn bị/chọn một môi
trường Windows Python có dependencies tương ứng trước khi chạy lại. Không dùng
các lệnh đường dẫn venv cũ trong hồ sơ lịch sử như môi trường đang sẵn có.

Sau khi đã chọn đúng interpreter/môi trường, ví dụ provision runtime đếm token
ngoài codebase rồi chạy kiểm tra M1 từ D:/KLTN/VGAR:

```powershell
python -m pip install --target 'D:/KLTN/runtime/m1-tokenizers' --no-deps `
  -r scripts/requirements_m1_tokenizer.txt
$env:PYTHONPATH = 'D:/KLTN/runtime/m1-tokenizers'
python scripts/run_m1_tests.py
python scripts/accept_m1_tokenizer.py `
  --tokenizer-manifest artifacts/m1/tokenizer-acceptance/tokenizer_manifest.json `
  --graph-output 'D:/KLTN/reports/vgar_m1_20261003/graph_m1_tokenizer_no_jedi.json' `
  --output-directory artifacts/m1/tokenizer-acceptance
```

Các lệnh trên là hướng dẫn chạy lại, chưa được thực thi trong lần viết tài liệu.
Thư viện tokenizer optional nếu chưa provision: một lượt tests có skip không
thay cho bằng chứng 95/95 không skip. Sau khi source Python đổi hoặc ghép commit
main, rebuild graph trước retrieval; số liệu checkpoint cũ thuộc snapshot cũ.
Tài liệu này không yêu cầu cài Torch hoặc tải model weights để kiểm tra tokenizer.
