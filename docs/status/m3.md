## 5. Pilot

**Lần chạy 1 (25/10, experiment `4a5907313405bd85`, attempt 1): hỏng hạ tầng, không dùng làm kết quả.** 6 cặp `TASK_EXCLUDED` đúng như dự kiến. Cả 9 cặp COLLECTED ra `ERROR INTERNAL_ERROR` ở stage `baseline` sau 6–18 s, VRAM ≤ 461 MiB (model chưa nạp). Nguyên nhân: `docker_probe.py` báo `PermissionError: '/vgar/config.json'`. `atomic_json` tạo file mode 0600, `docker cp` giữ nguyên uid 1000 và mode của host, còn root trong container chạy `--cap-drop ALL` nên không bỏ qua được phân quyền. Thư mục `/vgar` mode 0755 cũng làm probe không ghi được `result.json`. Lỗi chỉ xuất hiện khi chạy từ Linux, vì Windows không có mode POSIX. Đã tái hiện bằng container tối giản. Sửa ở `src/vgar/repair/docker_executor.py` (module M2, cần M2 review): chmod file trong `control` thành 0644 và thư mục thành 0777 trước khi `docker cp`. Test: `tests/m2/w910/test_docker_admission.py::test_control_dir_is_usable_by_capless_container_root`. Chạy lại 9 cặp bằng `--rerun` (attempt 2) với lý do "docker control dir permissions (Linux)".

**Lần chạy 2 (attempt 2, cùng experiment): lỗi task input, không dùng làm kết quả.** Probe đã chạy được, nhưng cả 9 cặp ra `VERIFICATION_INCOMPLETE` ở baseline với lỗi "Required selector not collected: tests/vgar_w9_repro_*.py::…". Nguyên nhân: `capture_baseline` chỉ collect trong `fallback_scope`, còn task input M3 viết không đưa file repro vào `fallback_scope`. Task mẫu của M2 dùng `["tests"]` nên chứa sẵn file này. Đã sửa 3 file `configs/m3/w9_pilot/tasks/*.json` (thêm file repro vào đầu `fallback_scope`), nên `experiment_id` mới là **`55ee3300aca339e8`**. Preflight giờ báo `SELECTOR_OUTSIDE_SCOPE` cho trường hợp này. Kiểm 26/10 bằng cách chỉ chạy stage baseline với Docker thật, không nạp model: A0/A1 baseline PASS cả 3 task (Matplotlib 12 PASS / 2 FAIL, Xarray 665/1, Pylint 17/1, 0 ERROR; test repro FAIL đúng). A2 ra `BASELINE_NOT_QUALIFIED` vì thiếu mypy/Ruff (D9). Preflight `55ee3300aca339e8`: 9/9 FITS.

**Lần chạy 3 (experiment `55ee3300aca339e8`, attempt 1): A2 đúng dự kiến, A0/A1 hỏng hạ tầng.** A2 ra `VERIFICATION_INCOMPLETE` / `BASELINE_NOT_QUALIFIED` ở cả 3 task (D9); đây là kết quả dùng được. Matplotlib A2 có attempt 1 `INTERRUPTED` (bị dừng giữa chừng), runner tự chạy tiếp thành attempt 2. A0/A1 qua baseline nhưng ra `INTERNAL_ERROR` ở stage `prompt` ("Tokenizer worker failed"), VRAM ≤ 246 MiB. Nguyên nhân: `load_config` (`src/vgar/repair/config.py`, module M2) gọi `.resolve()` cho `interpreter`. Trên Linux `.venv/bin/python` là symlink, nên resolve ra Python gốc của uv, không có site-packages của venv (`No module named 'vgar'`). Sửa: chuẩn hóa `interpreter` bằng `os.path.abspath` (không đi theo symlink). Test: `tests/m2/w78/test_w78_config.py::test_load_config_keeps_venv_interpreter_symlink`. Kiểm 26/10: tokenizer worker thật render được chat template. `experiment_id` không đổi; chạy lại 6 cặp A0/A1 bằng `--rerun`.
