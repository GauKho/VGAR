# Log và trace đọc được (M3-W12) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Log console, trace JSON v2 và chế độ debug cho `solve --agent` và `chat`, sửa P1/P6/P8 chung, và ghi commit code + nhãn lỗi cho batch runner A0–A3.

**Architecture:** Hàm thuần không I/O (nhãn lỗi, trạng thái code, máy, phễu, thời gian, render) nằm trong module nhỏ riêng; host agent và chat chỉ gom dữ liệu rồi gọi chúng. Trace v2 chỉ thêm trường. PR 2 dùng lại `failure_class` và `code_state` của PR 1 cho runner/aggregate.

**Tech Stack:** Python 3.11, pytest, LangChain callbacks, FastMCP, transformers (chỉ để lọc log).

**Spec:** `docs/superpowers/specs/2026-11-03-m3-w12-trace-design.md`

## Global Constraints

- Không đổi logic repair, quyết định của host, prompt, policy (spec §8).
- Không in toàn văn prompt, diff, issue, output lệnh ra console hay trace (spec §2).
- Observability lỗi thì nuốt, không làm hỏng run (spec §2 phản mục tiêu).
- Trace v2 chỉ thêm trường; `calls`, `model_calls`, `runs`, `messages`, `result`, `duration_ms` giữ nguyên tên và nghĩa; `schema: "vgar-agent-trace-v2"`.
- Ba dòng `[status]`, `[run]`, `[trace]` của `solve --agent` và `[verdict]` của chat giữ nguyên nội dung.
- Test không cần GPU/Docker; chạy `.venv/Scripts/python -m pytest <file> -q -p no:cacheprovider` trên Windows.
- Không commit: người dùng tự commit. Mỗi "Commit" bên dưới là điểm dừng: ghi file list vào ledger.
- Không chép code mới vào `~/vgar-x2b` khi run X2b đang chạy.
- PR 2 (Task 8–9) chạm code runner M2: cần M2 review; branch đặt trên PR 1.

## Review Focus

- Trace v1 cũ (không có `schema`, `header`, `attempts`) phải vẫn vào `aggregate_agent_traces.py` và cho cùng bảng M1 như trước — test ở Task 7.
