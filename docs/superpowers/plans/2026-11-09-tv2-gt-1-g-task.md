- Produces:

```python
@dataclass(frozen=True)
class FrameFact:
    file: str; line: int; function: str | None; order: int

@dataclass(frozen=True)
class ErrorFact:
    exception_type: str; message: str; occurrences: int

@dataclass(frozen=True)
class CriterionFact:
    text: str; checked: bool | None

@dataclass(frozen=True)
class TaskFacts:
    frames: tuple[FrameFact, ...]; errors: tuple[ErrorFact, ...]; criteria: tuple[CriterionFact, ...]
    bug_signals: tuple[str, ...]; labels: tuple[str, ...]; failing_tests: tuple[str, ...]

def extract_task_facts(issue_text: str, *, failing_tests: Sequence[str] = (), labels: Sequence[str] = ()) -> TaskFacts
```

`failing_tests` được bỏ phần tử rỗng sau `strip`, bỏ trùng, sắp xếp. `labels` được `strip().lower()`, bỏ rỗng, bỏ trùng, sắp xếp. `bug_signals` là tập con đã sắp xếp của `error_message`, `failing_test`, `label`, `stack_frame`. Regex frame và dòng lỗi đúng như spec §5.1, §5.2; văn bản chuẩn hóa `\r\n` thành `\n` trước khi xét.

    overlay = _overlay("multi_package", ISSUE)
    assert overlay.nodes[0]["type"] == "Issue" and overlay.nodes[0]["properties"]["labels"] == []
    frame = _of(overlay, "StackTraceFrame")[0]
