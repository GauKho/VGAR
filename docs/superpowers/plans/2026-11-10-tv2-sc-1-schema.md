# TV2 · SC-1: schema S Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `contracts/schema.py` khai báo đủ `S = (TN, TE, beta, delta, Gamma)` cho mọi loại, validate tuyến tính không đệ quy, xuất `S` dạng dữ liệu kèm `SCHEMA_HASH`, và có số đo tuyến tính.

**Architecture:** `delta` và `Gamma` là dữ liệu cùng các check một lượt trong `validate_graph_document`. Test dựng document tối thiểu từ chính `S` rồi sinh mutant cho từng luật. Benchmark là script riêng, không nằm trong CI.

**Tech Stack:** Python 3.11+, pytest, thư viện chuẩn (không thêm thư viện).

**Spec:** `docs/superpowers/specs/2026-11-10-tv2-sc-1-schema-design.md`

## Global Constraints

- Chỉ dùng plan 2 tuần và proposal làm căn cứ; code có sẵn chỉ là hiện trạng.
- Giữ nguyên chữ ký `validate_graph_document(document, *, trusted_ids=frozenset())`, tên `NODE_TYPES`, `EDGE_ENDPOINTS`, `SCHEMA_VERSION = "vgar-schema-full-v5"`, `RESOLVER_PROFILE`. Không thêm profile, không đổi tên loại.
- Kiểu JSON: `string`, `integer`, `number`, `boolean`, `array`, `object`, có thể thêm `|null`. `integer` không nhận `bool`.
- `delta` chỉ gồm khóa builder luôn ghi và có code khác đọc (bảng spec §4.1); bảng cạnh spec §4.2.
- Bất biến mới: `port_owner`, `port_symbol`, `method_owner`, `failing_test_targets`, `ast_single_parent` (spec §4.3).
- `SCHEMA_HASH = "sha256:" + sha256(json.dumps(schema_description(), sort_keys=True, separators=(",", ":")).encode()).hexdigest()`.
- Không sửa artifact hay fixture đã commit để khớp luật mới. Graph đã lưu fail vì thiếu khóa thì bỏ khóa đó khỏi `delta` và ghi Ruling.
- Không thêm thư viện; không assert thời gian trong test.
- **Không `git commit`, không `git push`.** Không đưa `artifacts/sample_graph.db` và file lạ `olve --agent ...` vào commit. Không sửa `src` khi suite đang chạy.
- Lệnh test: `python -m pytest -q -p no:cacheprovider <file>`.

## Review Focus

1. Graph đã lưu từ builder cũ (`artifacts/sample_graph.db`, fixture JSON trong `tests/fixtures`) được nạp lại qua validate: không được fail vì luật mới (Task 5, chạy toàn bộ suite).
2. Incremental với `trusted_ids`: node được tin cậy bỏ qua check `delta` như các check từng phần tử khác; `Gamma` vẫn chạy (Task 1, Task 2).
3. Overlay task validate trên document gộp: `test_node_ids` của FailingTest trỏ vào Test của graph gốc vẫn qua (Task 2).
4. Module ngoài repo (`is_external` true, `path` null) vẫn phải có đủ khóa `delta` của Module (Task 1).
5. Hai graph giống hệt nhau ở hai máy cho cùng `SCHEMA_HASH` (Task 3, Task 5 trên WSL).
